# 10. Checklist pengumpulan

Sumber: halaman 6, 7, 8, 12, dan 13 guidebook yang dikirim pemilik. Halaman lain `[CEK sendiri]`.

## Batas waktu

**28 November 2026** (pendaftaran dan pengumpulan berkas). Karya yang terlambat atau tidak memenuhi ketentuan dapat dinyatakan tidak memenuhi syarat. Target kirim: **27 November**.

## Pendaftaran

- [ ] Formulir: `https://bit.ly/InnovationCompetition_HIMASI26`
- [ ] Ketua tim terdaftar sebagai penanggung jawab. (Tim satu orang: ketua sama dengan peserta.)
- [ ] Peserta hanya terdaftar dalam satu tim.
- [ ] Data formulir diisi lengkap dan benar.
- [ ] Bila lolos final: ikut technical meeting dan seluruh rangkaian kegiatan.

## Folder Google Drive

- [ ] Satu folder milik tim.
- [ ] **Nama folder:** `SD_NamaTim_NamaInstitusi` (contoh dari guidebook: `SD_CodeCrafters_UBSIYogyakarta`). `[ISI nama tim dan institusi]`
- [ ] Akses: **"Anyone with the link can view"**.
- [ ] Tautan folder dimasukkan ke formulir.
- [ ] Tautan tidak dihapus atau dibatasi selama penilaian.
- [ ] Semua berkas bisa dibuka dan diunduh dari akun lain sebelum batas waktu. Uji dengan jendela penyamaran atau akun berbeda.

## Isi folder

- [ ] Proposal proyek (PDF). Bebas dari penanda `[ISI]` dan `[REAL DATA]`.
- [ ] Slide presentasi.
- [ ] Tautan website aktif (file teks atau dokumen dengan tautan produksi). Untuk kategori website, tidak perlu `.apk`.
- [ ] Dokumentasi aplikasi: gambar dan demonstrasi (video demo, termasuk versi tanpa kamera).
- [ ] Berkas pendukung lain: register lisensi aset, daftar sumber, bukti peninjauan teks Jawa bila ada.

## Ketentuan karya (halaman 8)

- [ ] Berbasis website.
- [ ] Sesuai tema "From Ideas to Innovation".
- [ ] Orisinal, tidak mengandung plagiarisme (aset tercatat, tidak menyalin proyek lain).
- [ ] Memberi solusi atas masalah nyata (pendidikan dan budaya).
- [ ] Belum pernah juara di lomba sejenis. `[KONFIRMASI]`
- [ ] Tidak ada pornografi, kekerasan, perjudian, atau pelanggaran SARA. Perhatikan konten legenda.

## Uji sebelum kirim

- [ ] Tautan produksi dibuka di perangkat dan jaringan berbeda.
- [ ] Alur utama selesai tanpa kamera.
- [ ] Tidak ada galat di console.
- [ ] Tidak ada kunci API di repo atau klien.
- [ ] Teks Jawa semuanya punya status.
- [ ] Delivery Gate antislop tanpa FAIL.
- [ ] Video demo bisa diputar dari tautan Drive.
- [ ] Hosting tidak akan mati karena kuota: cek batas paket.

## Rencana saat tautan produksi bermasalah

1. Simpan versi statis cadangan di hosting lain (misalnya Cloudflare Pages).
2. Sertakan kedua tautan di berkas tautan.
3. Siapkan video demo penuh sebagai bukti fungsi.
